# 個人房貸試算器 (Windows Programming (II) 作業一)

## 專案簡介

本專案使用 **C# Windows Forms** 實作「個人房貸試算器」，提供房貸本息等額攤還(等額本息)的試算功能，並支援寬限期以及自備款比例 / 金額切換輸入。

## 功能說明

### 輸入項目

視窗左上方為輸入區，包含：

- **房屋總價 (Total House Price)**  
  - 控制項：`NumericUpDown`  
  - 單位：新台幣元（顯示千分位）  
  - 預設值：10,000,000 元  

- **自備款方式 (Down Payment)**  
  - 控制項：`RadioButton` + `NumericUpDown`  
  - 兩種模式擇一：
    - 比例輸入：例如 20%（預設）  
    - 金額輸入：例如 2,000,000 元  
  - 兩種模式切換時，只有對應的輸入框會顯示，避免混淆。  

- **貸款年利率 (Annual Interest Rate)**  
  - 控制項：`NumericUpDown`  
  - 單位：% / 年  
  - 小數點後兩位，預設值：2.15%  

- **貸款年限 (Loan Term)**  
  - 控制項：`NumericUpDown`  
  - 單位：年  
  - 範圍：1 ~ 40 年，預設 20 年  

- **寬限期 (Grace Period，選填)**  
  - 控制項：`NumericUpDown`  
  - 單位：年  
  - 範圍：0 ~ 10 年  
  - 寬限期間只繳利息、不繳本金。  

- **按鈕**  
  - 「開始試算」：觸發計算  
  - 「重置」：恢復成預設值並清空結果顯示  

### 輸出結果

視窗下方為結果區，會將數值格式化成**千分位 + 小數點後兩位**顯示：

- **貸款總金額**：房屋總價－自備款  
- **每月應繳金額 (本 + 息)**：寬限期過後等額本息月付金  
- **寬限期每月利息**：若有寬限期，顯示寬限期間每月應繳利息，否則顯示「—」  
- **首期利息**：第一個月利息金額  
- **首期本金**：  
  - 若無寬限期：首月本金 = 每月應繳金額 − 首期利息  
  - 若有寬限期：顯示「0.00（寬限中）」  
- **總利息支出**：寬限期利息 + 還款期利息總和  
- **總還款金額**：貸款本金 + 總利息支出  

底部附註：  
> 寬限期內僅繳利息；期滿後依剩餘期數本息均攤。

## 使用說明

1. 啟動程式後，在上方輸入區依序輸入：
   - 房屋總價
   - 自備款（選擇「比例」或「金額」後輸入）
   - 貸款年利率
   - 貸款年限
   - 寬限期（若無寬限期可維持為 0）

2. 按下 **「開始試算」** 按鈕。
3. 下方「試算結果」區會顯示：
   - 貸款總額
   - 每月應繳金額
   - 寬限期每月利息（若有）
   - 首期利息/本金
   - 總利息支出
   - 總還款金額

4. 若要重新試算其他條件，可按 **「重置」** 回到預設值。

## 輸入驗證與錯誤處理

程式中對以下情況做了檢查，避免程式崩潰：

- 房屋總價 ≤ 0 時，跳出警示視窗。
- 自備款金額 < 0 或 ≥ 房屋總價時，跳出警示。
- 貸款年限 ≤ 0 時，跳出警示。
- 寬限期 < 0 或 ≥ 貸款年限時，跳出警示。
- 所有計算包在 `try...catch` 中，若發生例外會顯示錯誤訊息而不當機。

## 計算公式與來源

本程式採用常見房貸「**等額本息**」還款方式。

- **等額本息月付金公式**  

  \[
  M = \frac{P \cdot r(1+r)^n}{(1+r)^n - 1}
  \]

  - \(M\)：每月應繳金額  
  - \(P\)：貸款本金（房屋總價 − 自備款）  
  - \(r\)：月利率 = 年利率 ÷ 12  
  - \(n\)：實際還款期數（月），需扣除寬限期月份  

- **寬限期內月付利息**  

  \[
  I_{\text{grace}} = P \times r
  \]

- **總利息支出**  
  - 若有寬限期：  
    - 寬限期利息總和 = \( I_{\text{grace}} \times \text{寬限月數} \)  
    - 還款期利息 = \( M \times \text{還款月數} - P \)  
    - 總利息 = 寬限期利息 + 還款期利息  
  - 若無寬限期：  
    - 總利息 = \( M \times n - P \)

- **總還款金額**  

  \[
  \text{TotalPayment} = P + \text{TotalInterest}
  \]

> 公式參考：  
> - 內政部不動產資訊平台房貸試算說明（等額本息公式）  
> - 一般銀行房貸宣傳資料與金融計算教學文章
